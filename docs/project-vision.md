# Mahjong Sensei 프로젝트 비전 및 목표 (Project Vision & Roadmap)

> **"마작은 단기적으로는 주사위 게임이지만, 장기적으로는 통계적 의사결정의 과학이다."**

---

## 1. 프로젝트 탄생 배경과 페인포인트 (Problem Statement)

리치 마작을 플레이하는 수많은 유저들은 다음과 같은 공통적인 심리적/인지적 딜레마를 겪습니다.

### 1.1 "억까"로 인한 멘탈 붕괴 (Tilt & Emotional Burnout)
- 아무리 패효율(Tile Efficiency)에 맞춰 정석대로 플레이하고 완벽히 수비를 해도, 타가의 이른 리치 일발 쯔모나 뒷도라(Uradora) 폭탄, 배패 5샹텐의 악조건이 겹치면 연속 라스(4위)를 박을 수밖에 없습니다.
- 유저는 **"내가 무엇을 잘못했는가?"**를 객관적으로 알지 못해 멘탈이 무너지고 틸트(Tilt) 상태에 빠져 비이성적인 플레이를 남발하게 됩니다.

### 1.2 "운빨 승리"로 인한 실력 착각 (Lucky Fluke Delusion)
- 반대로 수비 개념 없이 무지성으로 밀어붙였음에도 운 좋게 도라가 붙고 타가가 쏘아주어 1위를 차지했을 때, 유저는 자신의 잘못된 플레이가 "정답"이었다고 오판하여 나쁜 습관을 고착화합니다.

### 1.3 기존 분석 도구의 한계
- 기존의 작혼 전적 사이트(Amae-Koromo 등)는 누적 화료율, 방총률, 평순위 등 **최종 결과 수치**는 훌륭하게 보여주지만, **"그 게임에서 내 손패와 쯔모가 얼마나 좋았는가(Luck)"**와 **"내가 내린 타패 선택이 얼마나 최적이었는가(Skill)"**를 명확한 숫자로 분리해주지 못합니다.

## 2. Mahjong Sensei의 핵심 솔루션과 가치 제안 (Value Proposition)

Mahjong Sensei의 최종 목표는 **작혼 대국 패보 데이터를 정밀 분석하여, 매 게임과 최근 구간에서 유저의 운과 실력을 과학적으로 분리해주는 객관적인 나침반**이 되는 것입니다.

```
+-------------------------------------------------------------------+
|                        Mahjong Sensei                             |
|                                                                   |
|   최종 성적 (Rank / Score)  =  운 (Luck)  +  실력 (Skill)          |
|                                                                   |
|   • 배패 샹텐수 (평균 3.5 기준)     • 패효율 준수율 (최적 타패)     |
|   • 배패 적도라 & 도라 보유수       • 위험패 방총 실수율 (Deal-in)  |
|   • 유효 쯔모 획득률 (Draw Luck)   • 텐파이/오리 전환 정확도       |
|   • 뒷도라 적중 횟수               • 득실점 판단 합리성            |
+-------------------------------------------------------------------+
```

## 3. 핵심 기능 명세

### 3.1 운 점수 (Luck Score, 0~100점) 산출
- **배패 샹텐수 기여도**: 초기 배패가 평균(3.5샹텐)보다 얼마나 좋은가?
- **도라 기여도**: 배패에 도라 및 적도라를 몇 장 보유했는가?
- **유효 쯔모율 (Draw Luck)**: 샹텐수를 줄여주는 유효패를 몇 순 만에 쯔모했는가?
- **뒷도라(Uradora) 잭팟**: 리치 화료 시 뒷도라를 얼마나 획득했는가?
- **불가항력 대미지 (Unavoidable Damage)**: 타가의 쯔모 화료로 인해 깎인 실점(친 만관/하네만 쯔모 등)을 불운 지표로 보정.

### 3.2 실력 점수 (Skill Score, 0~100점) 산출
- **패효율 준수율 (Tile Efficiency)**: 매 순마다 유효패 매수를 최대로 남기는 정석 타패를 실행했는가?
- **방총 실수 감점 (Deal-in Penalty)**: 상대의 리치나 위협적인 울기 상태에서 위험패를 밀다가 쏘였는가?
- **내리기/수비 정확도 (Fold Accuracy)**: 현물, 스지, 카베 등 안전패 이론에 근거하여 실점을 성공적으로 회피했는가?

### 3.3 4사분면 퍼포먼스 매트릭스 (Performance Quadrants)

매 판의 결과를 `(운 점수, 실력 점수)` 좌표 평면에 매핑하여 4가지 유형으로 즉시 진단합니다.

```
            실력 점수 (Skill Score)
                     ▲
                     │
       [2사분면]     │     [1사분면]
     UNLUCKY_LOSS    │   SKILLFUL_WIN
   "억까 패배 (멘탈 케어)" │ "실력 & 운의 완벽한 승리"
   ------------------+------------------▶ 운 점수 (Luck Score)
       [3사분면]     │     [4사분면]
      SLUMP_LOSS     │   LUCKY_FLUKE
   "슬럼프 / 틸트 경고"  │ "운빨 승리 (피드백 필요)"
                     │
```

- **1사분면 (`SKILLFUL_WIN`)**: 실력도 좋았고 운도 따라준 완벽한 승리.
- **2사분면 (`UNLUCKY_LOSS`)**: **가장 중요한 멘탈 케어 영역.** 플레이는 최선이었으나 쯔모와 상대 화료 불운으로 패배함 ➔ *"자책하지 마세요, 올바른 플레이를 유지하세요."*
- **3사분면 (`SLUMP_LOSS`)**: 불운과 함께 타패 실수/무리한 밀기가 동반된 패배 ➔ 틸트 상태 진단 및 휴식 권고.
- **4사분면 (`LUCKY_FLUKE`)**: 실수는 많았으나 상대의 자멸이나 뒷도라 잭팟으로 이긴 게임 ➔ 주요 실수 타패 피드백 제공.

### 3.4 롤링 윈도우 통계 (Rolling Window Stats: 10 / 30 / 50판)
- 마작은 단 1판으로 평가할 수 없습니다.
- **최근 10판**: 현재 진행 중인 단기 틸트/상승세 감지.
- **최근 30판**: 중기적인 운/실력 밸런스 및 순위 추세 확인.
- **최근 50판**: 유저의 진정한 실력 지표(방총률 11% 미만, 화료율 22% 이상 등) 수렴 분석.
